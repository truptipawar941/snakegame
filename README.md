# 🐍 Snake Game - Python Project

## About the Project

This is a classic Snake Game built using Python and Pygame.  
The player controls a snake to eat food and increase score.
the game we played in childhood

---

## Features

- Score system
- High score saving
- 3 lives system
- Start screen and Game Over screen
- Restart option (R key)
- Performance message (Average / Better / Best)
